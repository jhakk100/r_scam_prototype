# 마음체크 — 최종 모델 연결본

`마음체크_시작.cmd`를 더블클릭하면 **이 컴퓨터에서만** 홈페이지가 열립니다. 공개 사이트에는 배포하지 않았습니다. 이미 실행 중이면 같은 서버를 다시 엽니다.

1. 대화를 붙여 넣거나 이미지를 선택해 문장을 추출합니다.
2. **문장 확인하기**에서 개인정보, 화자와 대화 순서를 확인합니다.
3. 확인란을 체크하고 **대화 분석하기**를 누릅니다.
4. 위험 지수와 간단한 결과 설명, 비슷한 대화 사례를 확인합니다.

브라우저만 닫으면 모델 서버가 계속 실행됩니다. 작업을 마치면 `마음체크_종료.cmd`를 실행해 GPU 메모리를 반환할 수 있습니다. 다음 실행의 주소는 `runtime/server.json`에 기록됩니다.

## 확인 결과와 수정 이유

전달받은 `maeum-check-source.zip`은 배포된 HTML·JS·CSS·이미지의 사본입니다. React/TypeScript 원본 프로젝트나 서버 코드는 포함하지 않습니다. 받은 압축 파일과 HTML은 저장소 밖의 기존 작업 폴더에 보존했습니다. Git에는 이번 홈페이지에서 실제로 사용하는 화면 코드와 이미지·OCR 실행 코드만 정리했습니다.

공개 주소 `https://maeum-check.leehyunjun0818.chatgpt.site`의 `/api/config`는 2026-10-24 확인 당시 `mode: rules`였습니다. 원래 화면은 8가지 항목의 가산점 합계를 요구하며, 최종 모델·D03 검색의 출력 계약과 다릅니다. 따라서 기존 결과 형식에 임의의 항목별 점수를 채우지 않고, 원래 홈페이지의 색감·카드 구성·말풍선 이미지를 유지한 편집 가능한 로컬 화면을 만들었습니다.

새 결과 화면은 위험 지수와 사용자가 이해하는 데 필요한 설명만 표시합니다. 모델명·검색 방식·연결 상태·계산식·모델별 점수 등 구현 정보는 홈페이지에서 제외했습니다. 위험 지수는 100점 만점의 참고 지수이며 실제 사기 확률이 아닙니다. 분석 신뢰도나 8개 항목별 설명·가산점은 만들어 내지 않습니다.

## 실제 연결 대상

- 코드와 실행 설정: `../V4/active_runtime.json`
- 최종 모델: `v3_finetuned_final`, 최종 학습 run `20261006_131323`의 E2B 어댑터
- 어댑터 fingerprint: `4f896fca6d1e441937d052fb9002a62b793cb786df7e8c2dd59f121082c2a5ff`
- 최종 검색: `D03_plain_text_tfidf_svd_xy`
- 검색 데이터: 검증된 학습 사례 226건, SCAM 113 / NON_SCAM 113
- 후보 8건에서 그룹 중복 제거 후 최대 5건. 입력의 정답·Z는 검색 거리에 사용하지 않습니다.
- 기존 데이터·모델·검색 설정·결합 계수는 수정하지 않았습니다.

Git에 보관하는 최신 홈페이지는 이 `homepage` 폴더입니다. 같은 저장소의 `V4`를 직접 사용하며, 이전 시연 폴더 `final/website`에 의존하지 않습니다. 저장소 밖의 기존 작업 폴더에서 실행하는 경우에도 형제 `r_scam_prototype/V4`를 찾을 수 있습니다.

새로 내려받은 저장소에서 이미지 입력을 사용하려면 최초 한 번 `python homepage/download_ocr.py`를 실행합니다. 다운로드 주소와 SHA-256은 `ocr-assets.json`에 기록했습니다. 대용량 OCR 실행 자산과 언어 데이터는 캐시로 취급하며 Git에 넣지 않습니다. 모델 환경과 가중치는 기존 V4 실행 안내에 따라 별도로 준비합니다.

## 입력과 개인정보

이미지 인식은 브라우저에서 Tesseract 6.0.1과 로컬 한국어·영어 자산으로 실행합니다. 이미지 원본을 모델 서버로 업로드하지 않습니다. OCR이 화자를 구별하지 못할 수 있으므로 확인 화면에서 반드시 수정합니다.

대화는 문장 확인 단계에서 일부 개인정보를 가린 뒤, 확인된 화자·문장만 `127.0.0.1` 서버에 보냅니다. 이름·주소 등 모든 정보를 자동으로 탐지하는 기능은 아닙니다. 대화와 결과를 서버 파일에 자동 저장하지 않습니다. 완료된 작업은 메모리에 약 15분간 남으며 서버 종료 시 사라집니다. 사용자가 결과 저장 버튼을 누르면 위험 지수·결과 설명·분석한 대화를 텍스트 파일로 내려받습니다.

발화 최대 96개, 문장 합계 12,000자이며, 모델의 별도 토큰 한도를 넘으면 오류로 안내합니다. 입력을 자동으로 자르거나 결과를 저장된 시연으로 대체하지 않습니다. 동시에 한 건씩 분석합니다.

## 파일과 검증

- `app/`: 편집 가능한 HTML·CSS·JavaScript
- `examples.json`: 홈페이지 예시와 기존 계산 결과. 이전 시연 폴더 없이 실행할 수 있습니다.
- `server.py`: 최종 시스템을 호출하는 로컬 API와 정적 파일 서버
- `start.ps1`, `stop.ps1`, `마음체크_시작.cmd`, `마음체크_종료.cmd`: 실행·종료
- `maeum-check-source/`: 원래 배포 파일과 보완한 OCR 자산
- `ocr-assets.json`: 보완 자산의 공개 출처와 SHA-256
- `verify_integration.py`: 실제 GPU 추론·HTTP 계약·이웃·결합식 검증
- `verify_package.py`: 모델을 로드하지 않고 저장소 안의 경로와 홈페이지 파일 제공을 검증
- `runtime/integration-verification.json`: 검증 결과. 입력 대화 원문은 기록하지 않습니다.

검증에서 저장 결과 512건의 재계산과 모델 파일 무결성이 통과했습니다. 실제 API로 주의·일상·새 대화를 다시 추론했고, 기존 두 예시의 최종 점수와 이웃이 일치했습니다. 이 확인은 시스템 연결과 계산 검증이며, 외부 데이터에 대한 정확도 검증을 뜻하지 않습니다.

이 연결본은 기존 Python 환경, 모델 가중치와 GPU가 있는 현재 컴퓨터용입니다. `app` 폴더만 다른 컴퓨터에 복사하면 실제 모델 추론은 실행되지 않습니다.
