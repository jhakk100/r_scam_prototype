# 별도 변형 검증 데이터셋

기존 테스트셋의 검증 표시가 있는 원본 20건을 참고해 생성했습니다.
SCAM 40건 / NON_SCAM 40건과 별도의 정보 부족 10건으로 총 90건입니다.
10개 주제 가족마다 이진 검증 8건(4:4)과 정보 부족 1건이 있습니다.

| 변형 유형 | SCAM | NON_SCAM | 별도 정보 부족 |
|---|---:|---:|---:|
| 말투·띄어쓰기·가벼운 오타 | 10 | 10 | 0 |
| 원본에 일상 대화 삽입 | 10 | 10 | 0 |
| 직접적 표현을 줄인 위험 사례 | 10 | 0 | 0 |
| 위험 단어를 포함한 정상 사례 | 0 | 10 | 0 |
| 앞 4턴이 같은 대조쌍 | 10 | 10 | 0 |
| 위험 발화 전 대화만 제공 | 0 | 0 | 10 |

## 파일

- `REVIEW_KO.md`: 각 대화, 원본 ID, 변형 유형, 임시 라벨 이유를 사람이 검토하는 파일.
- `dataset.json`: 전체 90건과 메타데이터.
- `binary-test.json`: 이진 ACC 계산용 80건. 라벨 검토 후 사용.
- `information-insufficient.json`: 정보 부족 10건. 이진 ACC에서 제외.
- `inputs.json`, `inputs.jsonl`: 정답·원본 라벨·변형 유형을 제거한 입력.
- `answers.jsonl`: 메시지와 분리한 임시 정답 및 평가 메타데이터.
- `source-reference.json`: 참고한 원본 20건의 스냅샷.
- `manifest.json`: 수량, 검사 결과, 원본 파일 해시와 한계.
- `build_variant_dataset.py`: 생성 코드 스냅샷. 재생성은 V4 상위 생성 스크립트에서 하며 기존 폴더 덮어쓰기를 거부합니다.

## 평가 기준

현재 모든 생성 사례는 `verified=false`입니다. 생성자가 작성한 임시 라벨이고 독립적인 사람 검증은 아직 없습니다.
위험 정황의 작업 라벨이며 실제 사건의 범죄 여부를 확정하는 정답이 아닙니다.
정보 부족은 원본 SCAM 라벨을 상속하지 않습니다. 사용자 의도에 따라 관찰 위험 LOW와 정보 부족 표시를 기대하며,
실제로 안전한 상대임을 뜻하지 않습니다. 위험 LOW 출력률과 정보 부족 표시율을 각각 확인해야 합니다.

현재 모델 실행·재학습·RAG 등록은 하지 않았습니다. 기존 활성 모델과 수식, 데이터, 논문도 보존했습니다.
향후 모델과 RAG를 고정하고 이 폴더의 사례를 검색 인덱스나 학습에 넣지 않은 상태에서 평가하세요.
변형 메시지로 임베딩과 특징을 새로 계산해야 하며 원본의 좌표·특징을 재사용하면 안 됩니다.
정답과 유형은 모델 입력에 넣지 말고 `messages`만 전달하세요. RAG에는 변형 ID와 원본 그룹 모두를 제외하세요.

권장 지표는 모델 단독·RAG 단독·결합 각각의 이진 ACC, 유형별 오류, 틀린 답에 0~1 또는 99~100점을 준 비율,
표현/일상 대화 변형 전후 판정 유지율, 대조쌍 동시 정답률, 정보 부족 표시율입니다.
이진 ACC는 기존 관례대로 LOW=NON_SCAM, HIGH=SCAM, UNKNOWN=오답으로 계산하고 UNKNOWN 수를 별도로 제시합니다.
원본과 비교하려면 `source-reference.json`의 해당 원본을 같은 고정 파이프라인으로 평가하세요.

원본을 참고한 합성 도전 세트이며 외부 현실 데이터에 대한 일반화 성능의 증거로 취급하면 안 됩니다.
같은 가족과 대조쌍은 상관된 표본입니다. 80개 독립 사례로 간주하거나 일부를 학습에 넣고 나머지를 검증하면 안 됩니다.
주제와 라벨을 균등하게 구성했으므로 실제 운영에서의 발생 비율을 재현하지도 않습니다.
